# Classmates Photos Directory

Place your classmates' photo files here!

### How to use:
1. Copy your classmates' pictures into this folder (`public/classmates/`).
   - Example: `student1.jpg`, `sarah.png`, `john.jpeg`, etc.
2. Open `src/data/classmates.js` and set the `image` property to the filename:
   ```js
   image: '/classmates/student1.jpg'
   ```
3. If an image is not provided or not found, the gallery will automatically generate a handsome portrait badge with their initials and chosen color!
